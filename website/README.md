# Сайт Typo AI

Статическая страница без зависимостей. `index.html` открывается напрямую. Для локального предпросмотра из корня проекта запустите

```sh
python3 -m http.server 8741 --bind 127.0.0.1 --directory website
```

Затем откройте http://127.0.0.1:8741/.

В разделе «Typo в действии» три циклических примера. Редактура по очереди показывает четыре стиля. При включённом уменьшении движения шаги переключаются вручную. «Установка» показывает три способа установки.

Публичная сборка скачивается из релиза GitHub. GitHub Pages публикует страницу из каталога `website`.
